# GravOS
GravOS is a simple, web based operating system with a basic desktop interface.
The operating system is themed personalized to Grav, a robotic assistant that helps Vitri on their space travels.
Grav is a character from SuperOrbital, which is one of the games I made recently.

## How to use
Click the **Try it** link above to see the WebOS. You can click on the buttons on the bottom to open apps, and the **X** icon in the top right of the window will close the app. In the Welcome app, you can click the **Next** button to advance Grav's dialogue.

## Features
1. A working clock set in the year 20XX
2. A welcome app with dialogue lines that you can advance by pressing a button
3. An app with a short paragraph about the game SuperOrbital and a link where you can play the game
4. A todo list app where you can write down tasks, check them off when you complete them, add new ones, or delete them.
